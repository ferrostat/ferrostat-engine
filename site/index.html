The programs are not signed. On Linux and macOS make the file executable first (chmod +x); macOS may also need xattr -d com.apple.quarantine <file>, and Windows may ask you to confirm under “More info → Run anyway”. Archives with both programs are attached to each release.

Development builds from main

Three front ends, one engine

Command line

An interactive prompt, plus batch mode for scripts: ferrostat --do analysis.do.

Desktop

Results, data browser, do-file editor with syntax highlighting, and a graph viewer.

Browser

The same engine compiled to WebAssembly. Nothing to install; files stay on your machine.

Quick start

$ chmod +x ferrostat-linux-x86_64
$ ./ferrostat-linux-x86_64
. use mydata.dta, clear
. regress y x1 x2, vce(robust)
. twoway scatter y x1 || lfit y x1
. graph export fit.png, replace
